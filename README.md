# Application de gestion des concours administratifs

Application PHP/MySQL avec HTML, CSS, JavaScript et Bootstrap.

## Installation
1. Copier le dossier dans `htdocs` (XAMPP) ou `www` (WAMP).
2. Créer une base MySQL nommée `concours_admin`.
3. Importer `database/concours.sql`.
4. Vérifier `config/database.php`.
5. Ouvrir `http://localhost/concours_administratifs/`.

## Comptes de démonstration
- Administrateur : admin@gmail.com / admin123
- Candidat : candidat@gmail.com / admin123

Les mots de passe de démonstration sont générés avec `password_hash`.
